# ETT Notes

ETT Notes is a responsive educational website designed to help students easily access and study Electronic & Telecommunication Technology (ETT) notes.

## Features

- 📚 ETT study notes
- 🔍 Easy navigation
- 📱 Responsive design
- 🎨 Clean and modern interface
- ⚡ Fast and user-friendly
- 🌐 Deployed using Vercel

## Technologies Used

- HTML
- CSS
- JavaScript
- React
- Vite

## Deployment

This project is deployed on Vercel.
